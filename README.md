# scrapy_parser_pep

## О проекте:

Проект педставляет из себя парсер для поиска и компановки информации о статусах PEP

## Как запустить 

1) Клонируйте репозиторий: `git@github.com:lavralex/scrapy_parser_pep.git`
2) Создайте и активируйте виртуальное окружение
3) Утсановите зависимости 

## Как использовать 

`scrapy crawl pep` - команда для запуска парсера, по окончанию работы парсра в results/ будут созданны 2 файла с данными

***pep*** - файл с информацией о PEP

***status_summary*** - файл со статусами PEP и количеством
